## 发现的问题

- `navida_jetson.launch.py` 会启动真实 `camera_publisher`。
- `camera_device:=test` 不是当前支持的测试源，会被当成真实设备路径，导致：

```text
Failed to open camera device: test
```

- 正常链路下的 zero Twist 已验证，但异常停车还没完整测试：
  - server 未启动
  - server 运行中关闭
  - HTTP timeout
  - 非法 action
  - 空 action
